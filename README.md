A chess engine in 4 KB of Python: negamax alpha-beta with quiescence, a transposition table, null-move pruning and piece-square evaluation, searching to a fixed node budget. It plays the make.fun house gauntlet through the env at MAKEFUN_ENV_URL.

## Run it

```sh
MAKEFUN_ENV_URL=http://store:8080 python3 main.py
```
